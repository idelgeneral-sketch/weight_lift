# ברזל · יומן אימונים (גרסה 2)

אפליקציית React‏ + Vite‏ + Supabase למעקב אחר תוכנית אימוני ההתנגדות. באותו מבנה עבודה כמו `shop_list_app`: Vite + Supabase, פריסה ל-Render עם CI מ-GitHub.

## מסכים וזרימה

1. **מסך פתיחה** — כפתור "אימונים"
2. **מסך אימונים** — כפתור לכל סוג אימון (אימון אחד / שתיים / שלוש), מגיע מטבלת `workout_types`
3. **מסך רשימת תרגילים** (לפי סוג האימון) — 14 התרגילים עם משקל מוצג באפור וחסום לעריכה. תפריט המבורגר (☰) מימין למעלה עם אופציית **"שינוי משקלים"** — פותח את שדות המשקל לעריכה, ומציג בתחתית כפתור **"שמור"** ששומר את כל הערכים בבת אחת. כשלא בעריכה, מוצג בתחתית כפתור **"התחל"**.
4. **מסך אימון** (נפתח בלחיצה על "התחל") — כותרת עם תאריך היום, רשימת התרגילים עם השם, המשקל (קריאה בלבד, באפור) וצ'ק-בוקס לסימון ביצוע. כפתור **"סיום"** בתחתית חוזר למסך הבית.

## מבנה טבלאות ב-Supabase

- **workout_types** — שלושת סוגי האימונים (`name`, `sort_order`)
- **exercises** — התרגילים של כל סוג אימון, כולל המשקל הנוכחי (`workout_type_id`, `slot_order`, `name`, `muscle_group`, `weight`)
- **workout_sessions** — אימון בפועל שנפתח בתאריך מסוים (`workout_type_id`, `session_date`) — נוצר אוטומטית בלחיצה על "התחל"; יש רק אימון אחד ליום לכל סוג
- **session_items** — מה בוצע בכל אימון בפועל: לכל תרגיל, תמונת מצב של המשקל שהיה רשום באותו רגע, וסימון בוצע/לא בוצע

## שלב 1: הקמת Supabase

1. צרו פרויקט חדש ב-[supabase.com](https://supabase.com).
2. בתפריט **SQL Editor**, הריצו את `supabase-schema.sql` — יוצר את ארבע הטבלאות, פותח מדיניות גישה (RLS) פשוטה, ומכניס את שלושת סוגי האימונים ואת 14 התרגילים לכל אחד מהם.
3. בתפריט **Project Settings → API**, העתיקו את `Project URL` ואת `anon public key`.

> **הערה על אבטחה:** מדיניות ה-RLS פתוחה לגמרי — מתאים לאפליקציה אישית ללא התחברות משתמשים.

## שלב 2: הרצה מקומית (רשות)

```bash
npm install
cp .env.example .env
# ערכו את .env עם הפרטים מ-Supabase
npm run dev
```

## שלב 3: פריסה ל-Render

1. דחפו את הפרויקט ל-repo ב-GitHub.
2. ב-[Render](https://render.com), צרו **Static Site** המחובר ל-repo.
3. **Build Command:** `npm install && npm run build`
   **Publish Directory:** `dist`
4. הוסיפו משתני סביבה: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
5. Deploy — כל push ל-branch הראשי יריץ build אוטומטי.

## עדכון גרסה

כל שינוי שמשוחרר בפועל מעלה את המספר ב-`src/version.js` (`APP_VERSION`).
